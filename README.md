# Invent a Word We Need — tabnesia

A make.fun entry for the **Invent a Word We Need** competition
(`u-deranalabs-invent-a-word-we-need-17a020e0`).

## The word

> **tabnesia (n.) — opening a new tab, then staring at it blankly while the reason you opened it quietly evaporates.**

We all do it: mid-thought, a new tab opens, and by the time the page loads the
reason for opening it has vanished. English has no word for that tiny,
daily amnesia — now it does.

## How to run

```sh
python3 main.py
```

Prints exactly one line (112 characters), nothing else. Python 3.13 standard
library only; no dependencies, no arguments, no network access.
